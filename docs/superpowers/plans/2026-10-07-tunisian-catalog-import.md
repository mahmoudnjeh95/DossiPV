# Tunisian Catalog Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fill DossiPV's shared equipment catalog with the panels and inverters accepted in Tunisia (ANME / STEG lists), with characteristics extracted from manufacturer datasheets, plus generic cables and common protections — published only after super-admin review.

**Architecture:** A new CLI-only workspace package `@dossipv/catalog-import` downloads the official lists, parses them (`pdftotext -table`), reads manufacturer datasheets with `claude-opus-5-5` (structured output), validates every record with sanity rules, writes reviewable JSON under `data/catalog/`, then upserts into the shared catalog as `DRAFT`. A new `catalogStatus` column hides drafts from installers; a super-admin review page publishes them.

**Tech Stack:** TypeScript (ESM, Node ≥ 24), Prisma 7, `@anthropic-ai/sdk` 0.74 (`messages.parse` + `output_config.format`, the pattern already used in `packages/dossier-worker/src/generate-page-37-layout.ts`), zod 3, vitest 3, xpdf `pdftotext` 4.x, Next.js (admin page).

**Spec:** `docs/superpowers/specs/2026-10-07-installer-library-catalog-import-auto-sizing-design.md` §3 (Part 2).

## Global Constraints

- Node ≥ 24; every package is ESM TypeScript with `"main": "./src/index.ts"` (no build step), tests with vitest.
- The CLI runs on a developer machine only — never in the web app or on the server.
- `pdftotext` must be **xpdf 4.x** (Git for Windows ships it at `/mingw64/bin/pdftotext`); poppler's `pdftotext` has no `-table` mode. Path overridable with env `PDFTOTEXT_PATH`.
- Datasheet extraction model: `claude-opus-5-5`, `output_config.effort: "high"`. The installed SDK (0.74.0) has no `fallbacks` parameter; a `refusal` stop reason is recorded as an extraction failure for that datasheet.
- Nothing imported is visible to installers before a super-admin publishes it (`catalogStatus = DRAFT`).
- An import never changes the electrical values of a `PUBLISHED` item; it only refreshes homologation fields and notes the differences.
- Missing datasheet fields stay null; nothing is guessed. A record missing a field the database requires is reported, not imported.
- UI text is French; code, comments and file names are English.
- Production migrations are applied by hand by the user (`npm run migrate:deploy` in `packages/db`, through the SSH tunnel); the deploy workflow does not run them.
- Prices are out of scope for this part (Part 1 adds them, default 0).

## Review Focus

- A manufacturer name spread over several lines, or a model group continuing on the next page, in the STEG list → every model keeps the right brand (pinned in Task 1 by the full-fixture manufacturer counts).
- The same panel model listed twice with different validity dates in the ANME list → one entry, the latest date wins (Task 2 test).
- A datasheet that does not cover a model the registry asks for, or covers extra models → the missing model is reported, extra models are ignored, nothing is invented (Task 6 test).
- Re-running the import after a published item has been used in projects → its values stay, only homologation dates change, differences go to `importNotes` (Task 8 test).
- An expired homologation on equipment used by a project → warning C20 fires instead of being fed an empty list (Task 10 test).

`packages/catalog-import/src/parse-steg-list.ts`:
```ts
import type { StegInverterListing } from './types';

// One table row: [manufacturer fragment]  model  power W|VA  dd/mm/yyyy
const ROW = /^(.*?)\s{2,}([\d ]+?)\s?(?:W|VA)\s{2,}(\d{2})\/(\d{2})\/(\d{4})\s*$/;

const BRAND_ALIASES: Record<string, string> = {
  'Ningbo Ginlong Technologies SOLIS': 'SOLIS',
  'SHENZHEN KSTAR NEW ENERGY': 'KSTAR',
  'SHENZHEN SENERGY TECHNOLOGY': 'SENERGY',
  'Crown Micro FZCO': 'Crown Micro',
  'Heinrich Kopp GmbH': 'KOPP',
  'SMA SOLAR': 'SMA',
  'SOFAR SOLAR': 'SOFAR',
  'SOLAX POWER': 'SOLAX',
  'ZCS AZZURRO': 'ZCS Azzurro',
};

/**
 * Parses `pdftotext -table -enc UTF-8` output of the STEG accepted-inverter list. The manufacturer
 * cell is merged across its rows: its text appears on the group's first row(s) only, possibly
 * split over consecutive rows ("Ningbo Ginlong" / "Technologies" / "SOLIS"), and the group may
 * continue on the next page with no manufacturer text. A fragment on a row that follows a row
 * without one starts a new group; consecutive fragments extend the current group's name.
 */
export function parseStegList(text: string): StegInverterListing[] {
  const rows: { group: { parts: string[] }; model: string; acPowerW: number; acceptedUntil: string }[] = [];
  let group: { parts: string[] } | null = null;
  let previousRowHadFragment = false;

  for (const rawLine of text.split(/\r?\n/)) {
    const match = ROW.exec(rawLine.trim());
    if (!match) continue;
    const [, cells, power, day, month, year] = match;
    const tokens = cells!.split(/\s{2,}/);
    const model = tokens.pop()!.trim();
    const fragment = tokens.join(' ').trim();
    if (fragment) {
      if (previousRowHadFragment && group) group.parts.push(fragment);
      else group = { parts: [fragment] };
    }
    previousRowHadFragment = fragment !== '';
    if (!group) continue; // rows before any manufacturer cannot be attributed
    rows.push({ group, model, acPowerW: Number(power!.replace(/ /g, '')), acceptedUntil: `${year}-${month}-${day}` });
  }

  return rows.map(({ group: g, model, acPowerW, acceptedUntil }) => {
    const manufacturer = g.parts.join(' ');
    return { manufacturer, brand: BRAND_ALIASES[manufacturer] ?? manufacturer, model, acPowerW, acceptedUntil };
  });
}
```

```ts
import type { AnmePanelListing } from './types';

const ROW = /^(.*\S)\s{2,}(\d{2})\/(\d{2})\/(\d{4})\s*$/;
const COUNTRIES = new Set([
  'chine', 'tunisie', 'roumanie', 'croatie', 'allemagne', 'italie', 'jordanie', 'turquie', 'inde',
  'vietnam', 'malaisie', 'thaïlande', 'corée', 'japon', 'espagne', 'france', 'singapour', 'indonésie',
  'laos', 'cambodge', 'égypte', 'maroc', 'états-unis', 'pays-bas',
]);
const BRAND_PREFIXES: [RegExp, string][] = [
  [/^LONGi/i, 'LONGi'], [/^JinKo/i, 'Jinko'], [/^Shanghai JA Solar|^JA Solar/i, 'JA Solar'],
  [/^Trina/i, 'Trina'], [/^Canadian Solar/i, 'Canadian Solar'], [/^ALTERNATIVE ENERGY \(AE\)/i, 'AE Solar'],
  [/^ALPHANIS/i, 'Alphanis'], [/^Chint/i, 'Astronergy'], [/^Anhui Huasun/i, 'Huasun'],
  [/^Tongwei/i, 'Tongwei'], [/^Risen/i, 'Risen'], [/^Zhejiang aiko/i, 'Aiko'], [/^ZNShine/i, 'ZNShine'],
  [/^Wuxi Suntech/i, 'Suntech'], [/^DAH Solar/i, 'DAH Solar'],
];

function brandOf(manufacturer: string): string {
  return BRAND_PREFIXES.find(([pattern]) => pattern.test(manufacturer))?.[1] ?? manufacturer;
}

function capitalize(country: string): string {
  return country.charAt(0).toUpperCase() + country.slice(1).toLowerCase();
}

/**
 * Parses `pdftotext -table -enc UTF-8` output of the ANME accepted-panel list. Columns are
 * separated by 2+ spaces, but manufacturer names and certificate references can contain double
 * spaces too, so the row is anchored on the country column. Rows the layout garbled (model and
 * certification body run together) are returned in `unparsedLines` for manual entry.
 */
export function parseAnmeList(text: string): { listings: AnmePanelListing[]; unparsedLines: string[] } {
  const byModel = new Map<string, AnmePanelListing>();
  const unparsedLines: string[] = [];

  for (const rawLine of text.split(/\r?\n/)) {
    const line = rawLine.trim();
    const match = ROW.exec(line);
    if (!match) continue;
    const [, cells, day, month, year] = match;
    const tokens = cells!.split(/\s{2,}/);
    const countryIndex = tokens.findIndex((token) => COUNTRIES.has(token.toLowerCase()));
    if (countryIndex < 1 || tokens.length < countryIndex + 4) {
      if (!/en date du/i.test(line)) unparsedLines.push(line);
      continue;
    }
    const manufacturer = tokens.slice(0, countryIndex).join(' ');
    const listing: AnmePanelListing = {
      manufacturer,
      brand: brandOf(manufacturer),
      country: capitalize(tokens[countryIndex]!),
      model: tokens[countryIndex + 1]!.replace(/\s+-\s+[A-Za-zÀ-ÿ]+$/, '').trim(),
      certificationBody: tokens[countryIndex + 2]!,
      certificateReference: tokens.slice(countryIndex + 3).join(' '),
      validUntil: `${year}-${month}-${day}`,
    };
    const existing = byModel.get(listing.model);
    if (!existing || existing.validUntil < listing.validUntil) byModel.set(listing.model, listing);
  }

  return { listings: [...byModel.values()], unparsedLines };
}
```

```ts
import { execFile } from 'child_process';
import { promisify } from 'util';

const execFileAsync = promisify(execFile);

/** xpdf 4.x pdftotext (`-table` does not exist in poppler's build). */
export async function pdfToText(pdfPath: string, mode: 'table' | 'layout'): Promise<string> {
  const binary = process.env.PDFTOTEXT_PATH ?? 'pdftotext';
  const { stdout } = await execFileAsync(binary, [`-${mode}`, '-enc', 'UTF-8', pdfPath, '-'], {
    maxBuffer: 64 * 1024 * 1024,
  });
  return stdout;
}
```

```ts
import { mkdir, writeFile } from 'fs/promises';
import { tmpdir } from 'os';
import { join } from 'path';
import { download } from './datasheet-cache';
import { pdfToText } from './pdf-text';
import { parseStegList } from './parse-steg-list';
import { parseAnmeList } from './parse-anme-list';
import { DATA_DIR, SOURCE_LISTS } from './sources';

async function writeJson(relativePath: string, value: unknown): Promise<void> {
  const fullPath = join(DATA_DIR, relativePath);
  await mkdir(join(fullPath, '..'), { recursive: true });
  await writeFile(fullPath, `${JSON.stringify(value, null, 2)}\n`);
}

async function fetchLists(): Promise<void> {
  const fetchedAt = new Date().toISOString();

  const stegPdf = join(tmpdir(), 'dossipv-steg.pdf');
  await download(SOURCE_LISTS.stegInverters, stegPdf);
  const steg = parseStegList(await pdfToText(stegPdf, 'table'));
```

```ts
import { z } from 'zod';

const familySchema = z.object({
  kind: z.enum(['PV_MODULE', 'INVERTER']),
  brand: z.string().min(1),
  url: z.string().url().startsWith('https://'),
  models: z.array(z.string().min(1)).min(1),
});

export type DatasheetFamily = z.infer<typeof familySchema>;

export function parseRegistry(json: unknown): DatasheetFamily[] {
  return z.array(familySchema).parse(json);
}

export function checkRegistryAgainstListings(
  families: DatasheetFamily[],
  panelModels: Set<string>,
  inverterModels: Set<string>,
): string[] {
  const problems: string[] = [];
  const seen = new Set<string>();
  for (const family of families) {
    const listed = family.kind === 'PV_MODULE' ? panelModels : inverterModels;
    for (const model of family.models) {
      if (seen.has(model)) problems.push(`${model} : présent dans plusieurs fiches.`);
      seen.add(model);
      if (!listed.has(model)) {
        problems.push(`${model} : absent de la liste officielle ${family.kind === 'PV_MODULE' ? 'ANME' : 'STEG'}.`);
      }
    }
  }
  return problems;
}
```

```ts
import type { StegInverterListing } from './types';

export interface PvModuleRecord {
  model: string;
  pmaxW: number | null; vmpV: number | null; impA: number | null; vocV: number | null; iscA: number | null;
  tempCoeffVocPct: number | null; tempCoeffIscPct: number | null; tempCoeffPmaxPct: number | null; tempCoeffVmpPct: number | null;
  irmA: number | null; maxSystemVoltageV: number | null;
  bifacial: boolean; bifacialGainPct: number | null;
  lengthMm: number | null; widthMm: number | null; weightKg: number | null; noctC: number | null;
  sourcePages: number[];
}

export interface InverterRecord {
  model: string;
  phases: number | null; pacW: number | null; sacVA: number | null; vdcMaxV: number | null;
  mpptMinV: number | null; mpptMaxV: number | null; startUpV: number | null;
  mpptCount: number | null; inputsPerMppt: number | null; idcMaxPerMpptA: number | null; iscMaxPerMpptA: number | null;
  vacNomV: number | null; vacRangeV: string | null; iacMaxA: number | null; integratedDcSwitch: boolean | null;
  sourcePages: number[];
}

export interface ValidationResult { errors: string[]; warnings: string[] }

const MODULE_REQUIRED = ['pmaxW', 'vmpV', 'impA', 'vocV', 'iscA', 'tempCoeffVocPct', 'tempCoeffIscPct', 'tempCoeffPmaxPct', 'irmA', 'maxSystemVoltageV', 'lengthMm', 'widthMm', 'weightKg'] as const;
const INVERTER_REQUIRED = ['phases', 'pacW', 'sacVA', 'vdcMaxV', 'mpptMinV', 'mpptMaxV', 'startUpV', 'mpptCount', 'inputsPerMppt', 'idcMaxPerMpptA', 'iscMaxPerMpptA', 'vacNomV', 'iacMaxA'] as const;

function outOfRange(value: number, min: number, max: number): boolean {
  return value < min || value > max;
}

export function validatePvModule(r: PvModuleRecord): ValidationResult {
  const errors = MODULE_REQUIRED.filter((key) => r[key] === null).map((key) => `${key} manquant sur la fiche.`);
  const warnings: string[] = [];
  if (r.vmpV !== null && r.vocV !== null && r.vmpV >= r.vocV) errors.push(`Vmp (${r.vmpV}) doit être inférieur à Voc (${r.vocV}).`);
  if (r.impA !== null && r.iscA !== null && r.impA >= r.iscA) errors.push(`Imp (${r.impA}) doit être inférieur à Isc (${r.iscA}).`);
  if (r.pmaxW !== null && r.vmpV !== null && r.impA !== null) {
    const product = r.vmpV * r.impA;
    if (Math.abs(r.pmaxW - product) / r.pmaxW > 0.03) errors.push(`Pmax (${r.pmaxW}) ≠ Vmp × Imp (${product.toFixed(1)}) à plus de 3 %.`);
  }
  if (r.tempCoeffVocPct !== null && outOfRange(r.tempCoeffVocPct, -0.35, -0.2)) errors.push(`Coefficient Voc (${r.tempCoeffVocPct} %/°C) hors de la plage -0.35…-0.2.`);
  if (r.tempCoeffIscPct !== null && outOfRange(r.tempCoeffIscPct, 0, 0.1)) errors.push(`Coefficient Isc (${r.tempCoeffIscPct} %/°C) hors de la plage 0…0.1.`);
  if (r.tempCoeffPmaxPct !== null && outOfRange(r.tempCoeffPmaxPct, -0.45, -0.25)) errors.push(`Coefficient Pmax (${r.tempCoeffPmaxPct} %/°C) hors de la plage -0.45…-0.25.`);
  if (r.maxSystemVoltageV !== null && r.maxSystemVoltageV !== 1000 && r.maxSystemVoltageV !== 1500) warnings.push(`Tension système max inhabituelle (${r.maxSystemVoltageV} V).`);
  if (r.lengthMm !== null && outOfRange(r.lengthMm, 1000, 2600)) errors.push(`Longueur (${r.lengthMm} mm) improbable.`);
  if (r.widthMm !== null && outOfRange(r.widthMm, 900, 1400)) errors.push(`Largeur (${r.widthMm} mm) improbable.`);
  if (r.weightKg !== null && outOfRange(r.weightKg, 10, 45)) errors.push(`Poids (${r.weightKg} kg) improbable.`);
  return { errors, warnings };
}

export function validateInverter(r: InverterRecord, listing: StegInverterListing | undefined): ValidationResult {
  const errors = INVERTER_REQUIRED.filter((key) => r[key] === null).map((key) => `${key} manquant sur la fiche.`);
  const warnings: string[] = [];
  if (r.phases !== null && r.phases !== 1 && r.phases !== 3) errors.push(`Nombre de phases (${r.phases}) invalide.`);
  if (r.mpptMinV !== null && r.mpptMaxV !== null && r.mpptMinV >= r.mpptMaxV) errors.push(`Plage MPPT incohérente (${r.mpptMinV}–${r.mpptMaxV} V).`);
  if (r.mpptMaxV !== null && r.vdcMaxV !== null && r.mpptMaxV > r.vdcMaxV) errors.push(`Plage MPPT max (${r.mpptMaxV} V) au-dessus de la tension DC max (${r.vdcMaxV} V).`);
  if (r.pacW !== null && r.sacVA !== null && r.pacW > r.sacVA) errors.push(`Puissance active (${r.pacW} W) supérieure à l'apparente (${r.sacVA} VA).`);
  if (listing && r.pacW !== null && Math.abs(r.pacW - listing.acPowerW) / listing.acPowerW > 0.01) {
    errors.push(`Puissance AC (${r.pacW} W) différente de la liste STEG (${listing.acPowerW} W).`);
  }
  if (r.pacW !== null && r.vacNomV !== null && r.iacMaxA !== null && r.phases !== null) {
    const nominal = r.pacW / (r.vacNomV * (r.phases === 3 ? Math.sqrt(3) : 1));
    if (r.iacMaxA < nominal * 0.95) warnings.push(`Courant AC max (${r.iacMaxA} A) inférieur au courant nominal calculé (${nominal.toFixed(1)} A).`);
  }
  return { errors, warnings };
}
```

```ts
  family: DatasheetFamily,
  pdf: Buffer,

  const response = await client.messages.parse({
    model: 'claude-opus-5-5',
    max_tokens: 16000,
    output_config: { effort: 'high', format: isModule ? MODULE_FORMAT : INVERTER_FORMAT },
    messages: [
      {
        role: 'user',
        content: [
          { type: 'document', source: { type: 'base64', media_type: 'application/pdf', data: pdf.toString('base64') } },
          {
            type: 'text',
            text: `${isModule ? MODULE_INSTRUCTIONS : INVERTER_INSTRUCTIONS}\n\nModèles demandés (${family.brand}) :\n${family.models.join('\n')}`,
          },
        ],
      },
    ],
  });

  if (response.stop_reason === 'refusal') throw new DatasheetRefusedError(family.url);
  const output = response.parsed_output as { records: (PvModuleRecord | InverterRecord)[] } | null;
  if (!output) throw new Error(`Réponse illisible pour ${family.url}.`);

  const wanted = new Set(family.models);
  const records = output.records.filter((record) => wanted.has(record.model));
  const found = new Set(records.map((record) => record.model));
  return { records, missingModels: family.models.filter((model) => !found.has(model)) };
}
```

```ts
export interface ExistingItem {
  id: string;
  catalogStatus: 'DRAFT' | 'PUBLISHED';
  values: Record<string, unknown>;
}

export type ImportAction =
  | { kind: 'skip'; reason: string }
  | { kind: 'create' }
  | { kind: 'update-draft' }
  | { kind: 'refresh-published'; differences: string[] };

export function planImport(
  existing: ExistingItem | null,
  incoming: { errors: string[]; values: Record<string, unknown> },
  requiredKeys: readonly string[],
): ImportAction {
  const missing = requiredKeys.filter((key) => incoming.values[key] === null || incoming.values[key] === undefined);
  if (missing.length > 0) return { kind: 'skip', reason: `${missing.join(', ')} manquant` };
  if (!existing) return { kind: 'create' };
  if (existing.catalogStatus === 'DRAFT') return { kind: 'update-draft' };
  const differences = Object.entries(incoming.values)
    .filter(([key, value]) => key in existing.values && existing.values[key] !== value)
    .map(([key, value]) => `${key} : ${String(existing.values[key])} → ${String(value)}`);
  return { kind: 'refresh-published', differences };
}
```

```ts
  return Object.fromEntries(keys.map((key) => [key, (entry as Record<string, unknown>)[key] ?? null]));

function notesOf(entry: { errors: string[]; warnings: string[] }, extra: string[] = []): string | null {
  const lines = [...entry.errors.map((e) => `Erreur : ${e}`), ...entry.warnings.map((w) => `À vérifier : ${w}`), ...extra];
  return lines.length > 0 ? lines.join('\n') : null;

async function uploadDatasheet(url: string, model: string): Promise<string> {

  const { storageKey } = await saveFile(buffer, `${model}.pdf`, 'application/pdf');
  const file = await db.file.create({ data: { fileName: `${model}.pdf`, mimeType: 'pdf', storageKey } });
  return file.id;

export async function runImport({ dryRun }: { dryRun: boolean }): Promise<void> {

  const inverters = JSON.parse(await readFile(join(DATA_DIR, 'inverters.json'), 'utf8')) as CatalogInverterEntry[];
  const counts: Record<string, number> = {};
  const count = (key: string): void => { counts[key] = (counts[key] ?? 0) + 1; };

  for (const entry of modules) {
    const values = pick(entry, MODULE_VALUES);
    const existing = await db.pvModule.findFirst({ where: { ownerCompanyId: null, brand: entry.brand, model: entry.model } });
    const action = planImport(existing ? { id: existing.id, catalogStatus: existing.catalogStatus, values: pick(existing, MODULE_VALUES) } : null, { errors: entry.errors, values }, MODULE_REQUIRED);
    count(`panneaux ${action.kind}`);
    if (dryRun || action.kind === 'skip') {
      if (action.kind === 'skip') console.log(`Ignoré ${entry.brand} ${entry.model} : ${action.reason}`);
      continue;
    }
    const homologation = { homologationReference: entry.homologationReference, homologationValidTo: new Date(entry.homologationValidTo), datasheetSourceUrl: entry.datasheetSourceUrl };
    if (action.kind === 'create') {
      await db.pvModule.create({

      });
    } else if (action.kind === 'update-draft') {
      await db.pvModule.update({ where: { id: existing!.id }, data: { ...(values as object), ...homologation, importNotes: notesOf(entry) } as never });

        where: { id: existing!.id },
```

```ts
import { revalidatePath } from 'next/cache';
import { db } from '@dossipv/db';
import { requireAuthenticatedSuperAdmin } from '../layout';

export type ReviewKind = 'PV_MODULE' | 'INVERTER';

const PATH = '/admin/catalog-review';

export async function publishCatalogItemAction(kind: ReviewKind, id: string): Promise<void> {
  if (!(await requireAuthenticatedSuperAdmin())) return;
  const args = { where: { id, catalogStatus: 'DRAFT' as const }, data: { catalogStatus: 'PUBLISHED' as const, importNotes: null } };
  if (kind === 'PV_MODULE') await db.pvModule.update(args);
  else await db.inverter.update(args);
  revalidatePath(PATH);
}

export async function publishCleanDraftsAction(kind: ReviewKind): Promise<void> {
  if (!(await requireAuthenticatedSuperAdmin())) return;
  const args = { where: { ownerCompanyId: null, catalogStatus: 'DRAFT' as const, importNotes: null }, data: { catalogStatus: 'PUBLISHED' as const } };
  if (kind === 'PV_MODULE') await db.pvModule.updateMany(args);
  else await db.inverter.updateMany(args);
  revalidatePath(PATH);
}

export async function rejectCatalogItemAction(kind: ReviewKind, id: string): Promise<{ error: string } | undefined> {
  if (!(await requireAuthenticatedSuperAdmin())) return undefined;
  const args = { where: { id, catalogStatus: 'DRAFT' as const } };
  try {
    if (kind === 'PV_MODULE') await db.pvModule.delete(args);
    else await db.inverter.delete(args);
  } catch {
    return { error: 'Suppression impossible : cet équipement est déjà utilisé.' };
  }
  revalidatePath(PATH);
  return undefined;
}
```
